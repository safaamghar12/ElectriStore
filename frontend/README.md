# Système de Gestion de Magasin Alimentaire

## 🎯 Objectif
Développer une application web de gestion d'un magasin alimentaire permettant de centraliser et de simplifier la gestion des produits, des catégories, des stocks et des ventes.

## 🛒 Présentation du projet
FoodStore est une application de gestion destinée aux magasins alimentaires. Elle permet à l'administrateur de gérer les opérations quotidiennes du magasin à travers un tableau de bord simple et intuitif.

## Fonctionnalités principales

- **Dashboard :** consulter les indicateurs clés et les statistiques du magasin.
- **Gestion des produits :** ajouter, modifier, supprimer et rechercher des produits alimentaires.
- **Gestion des catégories :** organiser les produits par catégories.
- **Gestion des stocks :** suivre les quantités disponibles, détecter les stocks faibles et les ruptures de stock.
- **Gestion des ventes :** enregistrer les ventes et suivre leur évolution.
- **Statistiques :** analyser les produits, les stocks et les performances commerciales.
- **Paramètres :** gérer les informations et les préférences de l'application.

## 🛠️ Technologies utilisées

- Frontend : Angular
- Backend : Symfony
- Base de données : MySQL / MariaDB
- API : REST API

## 🎯 Objectif technique
Mettre en pratique le développement d'une application Full-Stack, la conception d'API REST, la gestion des données et l'organisation d'un projet Angular selon une architecture Feature-Based.
